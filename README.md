Color calculator

## Description

**version 1.0**

Calculates Euclidean distance of RGB colors and gives advice on ignoring certain colors or color pairs depending on the type of colorblindness one might have.


Jeremy Anderson

## Example

To run the program, give the following commands:

```
"Enter first color: "
98 118 23
"Enter second color: "
61 239 78
"Enter type of colorblindness: "
red-green

```

Here is an example of the program running:

```
Enter two RGB colors between 0 and 255 in RGB format.
Enter first color: 
98 118 23
Enter second color: 
61 239 78
RGB Distance is: 137.967
Enter type of colorblindness(red-green, blue-yellow, and complete): 
red-green
Avoid these colors: Pure Red, Pure Green, Olive Green, Brown, Orange and Green together, or Dark Red on Black.
```
